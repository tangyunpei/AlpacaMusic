# 连贯粒子与音频示波器

设计方向确认于 2026-10-01：动态避免生硬；新增波形采用用户选择的“克制、清晰的录音示波器线条”。

点云封面保持原样。2026-10-01 的轨道、绸缎和星空改由独立原生 Metal 粒子舞台绘制；粒子使用固定身份和连续时间，形态、局部音频形变与缓慢镜头分层计算。音乐改变局部运动幅度，不乘入累计相位；按时间差平滑输入，暂停、后台和减少动态时冻结完整姿态。SwiftUI 保持界面与切换控制。

“音频示波器”直接使用可分析播放源的有符号 PCM，固定满刻度，正向零交叉稳定窗口。连续采样保留原始时间顺序；窄窗口绘制时按桶保留极值。单根青白细线、极暗参考线与可选轻微光晕，不添加装饰波形或自动放大静音噪声。刷新采用温和的时间插值；切歌清除旧信号，暂停保持最后一帧。

当前 MusicKit 播放链路尚无可供分析的 PCM，因此粒子模式维持明确标注的氛围运动，示波器显示静候平线与说明。系统音频采集的公开接口路线仍待实现和实测，见 [Apple Music 音频分析调查](apple-music-audio-analysis.md)。静音和数据缺失均不生成模拟节拍。

音频分析新增全频幅度与低、中、高三个频带，保留原来的点云 energy/beat 含义。采样回调不执行 FFT；分析仍在工作队列运行。发布前核验采样代次，防止切歌或重置后旧分析结果回流。

粒子、示波器实现独立编写。视觉机制研究参考 [Mineradio-paused](https://github.com/XxHuberrr/Mineradio-paused/tree/d43de565acabfdc1a9c9820a27e81a98ccbebcef)；研究预览中的 GPL 着色器和 Three.js 没有引入产品。

- macOS 27 SDK 的 warnings-as-errors 弃用接口审计通过；正式构建最低 macOS 26.0、SDK 27.0，保留 MusicKit 与既有签名身份。

## 轨道波形与竖条频谱升级（2026-10-02）

“轨道光场”保留原有三维粒子环、不同倾角、互相穿插的空间关系、细密光粒及克制的光晕，不改为平面圆圈。三个粒子轨道分别读取真实低频、中频、高频带通 PCM，以各自采样驱动局部形变；不是把全频波形复制三遍，也不是以频带强弱生成正弦动画。画面不增加低、中、高标签。spectrumRing 持久化标识和原名称均保留，已有选择无需迁移。

新增“竖条频谱”。独立竖条按低频到高频从左至右排列，读取实际 FFT 频谱及频率间隔，采用对数频率分段；它是频域显示，与时间域的音频示波器及粒子轨道的波形形变有区别。输入以时间差平滑，不叠加无关的摆动。

暂停、后台及减少动态时保持已显示的完整帧；换曲清除旧采样。轨道光场没有音频采样时仍保留原有氛围运动，并明确标注无实时频谱；不会生成伪造的波形。音频示波器和竖条频谱在采样不可用时显示静候线/基线。Apple Music 当前通道也遵循此规则。

设置页使用四列选项，新增模式完整可选。点云、流光绸缎、深空航行及动态字幕的既有完整强调周期保持原有功能。

带通滤波采用固定增益的四阶 Butterworth 高/低截止，平滑交界，不做逐帧自动放大。原始 8192 点采样提供滤波预滚，三个输出与全频示波器共享同一段 1024 点源时间区间；真实滤波的相位响应保留。重置或格式改变后不复用旧滤波状态。系数公式参考 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)。


最终验证（2026-10-02）：

- 隔离原生 QA 中实际切换并观察了立体轨道及竖条频谱，保留原空间粒子外观，画面没有低、中、高文字标签。该 QA 使用明确标注的原始合成 PCM，不读取曲库/账号，不播放声音。

## 轨道节奏强调（2026-10-02）

原先每圈主要显示短 PCM 窗口的局部形变，鼓点对整片粒子的影响不明显。新增三组独立的音频瞬态响应，以各自真实带通 PCM 的 RMS、快速包络、较慢基线与正向上升检测起音；不使用播放器标量 beat，也不推断 BPM。固定增益保留强弱差异，持续长音与静音不反复触发。

真实起音让对应的立体轨道局部舒展、截面变厚、细颗粒与稀疏光晕变亮，约 30–40 ms 开始展开，600 ms 内完整回落。重复击打平滑叠加已启动的尾部，短暂采样中断和恢复也保持尾部。低频的空间推动更大，中频强调粒子层次，高频强调细光粒；原来的三维交错、旋转相位、视角及无频段文字标签保持。

节奏检测运行在视觉时钟，音频实时回调未增加工作。暂停、后台及减少动态保持包括节奏响应在内的完整帧；格式改变及源重置不产生假起音。没有 PCM 时不会产生节奏强调，Apple Music 当前限制仍见 apple-music-audio-analysis.md。

验证：423 项测试、35 个套件全部通过，包含 30/60/120 FPS 响应一致性、持续长音、20 Hz 不同采样相位、真正重复鼓点、独立频段、重叠完整收尾、短暂中断后恢复，以及普通/节能两种粒子密度的生产 Metal 绘制。SDK 27 接口审计通过，最低 macOS 26。

16 秒生产渲染预览使用原创 PCM 经过生产 AudioBandAnalysis 和 ParticleFieldMotionClock，包含独立起音、120 BPM 组合节奏、留白和密集加重。原始 WAV 与视频时间一致；有声预览、原图、起音前后对照及逐帧响应 CSV 保留在本地审查产物目录（未随仓库发布）。独立原生 QA 中也检查了组合节奏和减少动态状态；QA 不读取账号/曲库，不播放声音。该验证不证明 Apple Music 采样可用或用户已认可视觉质量。


正式安装：11 个变更文件及应用二进制与已验证版本一致，Apple Development 签名、Team ID 和 Bundle ID 校验通过。正式应用用 QQ 音乐测试曲目实际播放约半分钟，观察到进度、歌词及粒子轨道随播放变化；这项观察不等同于逐帧音画延迟测量。检查后恢复原曲、暂停与位置、音量、沉浸模式及视觉选择。曲库 SHA-256 前后一致。回滚备份保留在本机，未随仓库发布。


## 复古分段竖条频谱（2026-10-02）

按用户选择将连续渐变条重做为复古 LED 灯柱：72 列、随显示高度变化的 20–48 排分段亮格，暗色未亮灯格构成仪表底板。绿色主体、上部琥珀色与橙色亮格体现相同固定电平刻度，顶部细峰值标记短暂停留；无坐标网格、频率数字、频段标签或倒影。少量辉光集中在最上方亮格，末格按真实覆盖量渐亮，避免硬切造成机械闪跳。

频率仍按真实 FFT 分辨率从左至右对数排列，固定 dB 响应保持安静音乐较低，不做自动归一化。新增独立频谱时钟：约 22 ms 起音、220 ms 回落，峰值保持 140 ms 后按加速度下降。只在竖条频谱启用，既有音频示波器、粒子轨道和字幕逻辑保留。暂停、后台与减少动态冻结完整灯格/峰值状态；格式切换与音源重置清除旧状态。采样不可用只显示未亮灯格，不生成频谱。

验证：441 项测试、38 个套件通过，包含真实 Hz 映射、独立频带、固定增益、峰值保持与重拍、30/60/120 FPS 一致性、暂停恢复、静音收尾、异常元数据与紧凑/沉浸两种生产绘制。辉光边缘检查采用严格像素差异阈值，避免 GPU 边缘取整导致误判；不存在由时间生成的灯格。SDK 27 接口审计通过，正式最低 macOS 26，原开发者签名和 MusicKit 配置保留。

16 秒原始合成节奏经生产 AudioBandAnalysis、VisualizationClock 和 SpectrumBarsRenderer 导出，两种尺寸截图、连续有声预览和原始 WAV 保留在本地审查产物目录（未随仓库发布）。原生隔离 QA 已检查分段亮格与峰值标记的组合节奏显示，不访问曲库/账号。预览不代表 Apple Music 已具备采样，也不代表用户已认可最终视觉。


正式安装与重启检查：9 个变更文件和应用二进制与已验证版本一致，Apple Development 签名、Team ID、Bundle ID 校验通过。重启后已恢复原有网易云音乐测试曲目、暂停与位置、音量以及竖条频谱选项；重新进入沉浸模式后，动态字幕、歌词与新的分段底板可见。正式曲库 SHA-256 在安装和重启前后一致。节奏动态验证来自隔离原生 QA 与上述生产渲染预览，此次正式重启检查未额外播放歌曲。回滚备份保留在本机，未随仓库发布。


## 沉浸模式悬浮播放队列（2026-10-02）

底部播放队列按钮及菜单/快捷键只切换队列，不再强制退出沉浸。普通界面保留右侧队列栏；沉浸时复用队列内容作为右侧圆角悬浮面板，覆盖于视觉效果与歌词上方，不压缩或替换音频驱动的场景。按窗口空间限制宽高，面板避开底部播放控件；关闭按钮、底栏按钮、外围收起按钮或 Esc 先关闭队列。选曲继续保留沉浸模式，队列的排序、移除与清空操作沿用原逻辑。

队列打开时，覆盖的沉浸控件从可访问性树中暂时隐藏，浮层本身独立可操作；普通界面队列在沉浸时不重复挂载。透明外围使用明确的 SwiftUI Button 提供可访问的“收起播放队列”操作。

验证：441 项测试/38 套件通过，SDK 27 弃用接口审计通过；最低 macOS 26、Apple Development 签名与 MusicKit 配置保留。隔离原生 QA 使用正式 ContentView/AppModel/命令菜单、独立临时曲库与偏好、内存凭据和三首原创本地试听，检查了右侧圆角浮层、底栏与菜单打开、队列选曲、关闭按钮、Esc 优先收起和外围收起操作；未触碰真实账号。

正式安装与重启检查：4 个变更文件及应用二进制与验证版本一致，Apple Development 签名、Team ID、Bundle ID 校验通过。正式应用进入沉浸后，底栏队列按钮显示现有队列的右侧浮层，视觉和动态字幕仍留在原位；实际鼠标点击面板外后队列关闭，歌曲位置没有跳动。再打开后按 Esc 也只关闭浮层，保留沉浸及歌词。检查完成时保留浮层打开供用户查看；原有网易云音乐测试曲目、暂停与位置、静音状态保持。安装与重启后曲库 SHA-256 一致。回滚备份保留在本机，未随仓库发布。


## 三频段流光绸缎（2026-10-03）

保留三条柔软的立体粒子薄片及原来的暖桃、紫、青绿色。每条分别读取真实低频（20–250 Hz）、中频（250–4000 Hz）、高频（4000–20000 Hz）的带通 PCM，不再把三个播放器标量混用到所有缎带。沿用生产滤波的平滑交界及固定增益，画面不添加频段标签。

暖桃色低频带随对应的能量与起音整体舒展、加宽，紫色中频带呈现连续褶皱与翻卷，青绿色高频带加强细纹与边缘光泽。局部法向形变保留对应频段的有符号采样，亮度、颗粒大小与稀疏辉光也只使用本频段。三条均复用已有独立 RMS 与起音检测，约 30–40 ms 展开并在 600 ms 内完整回落，重复击打平滑叠加尾部。

时间相位与相机不受瞬时音量影响；暂停、后台和减少动态冻结完整帧，恢复时不跳到墙上时间。只有全局音量或标量 beat、没有带通 PCM 时不产生节奏强调。Apple Music 尚无实时采样的限制保持，不能以氛围流动冒充三频段响应。

验证：449 项测试、40 个套件全部通过。新增生产 Metal 绘制检查在普通/节能密度下验证独立有符号 PCM、各频段起音、真实 80/1000/8000 Hz 滤波、无采样与纯标量输入、异常极值，以及暂停/减少动态的完整像素冻结。色带判断使用同一生产背景并在线性光空间扣除背景，避免暗蓝梯度被误认为紫色缎带；独立输入的可见跨带变化低于 1%。真实滤波允许交界残留，同时要求目标缎带的变化超过其他两带变化总和。SDK 27 warnings-as-errors 接口审计通过，发布构建保持最低 macOS 26、原开发者签名与 MusicKit 配置。

12 秒原创三频段 PCM 经生产 AudioAnalyzer、AudioBandAnalysis 和 ParticleFieldMotionClock 导出，包含独立渐入、起音、120 BPM 组合节奏与收尾。连续有声视频、原始 WAV、逐帧分析 CSV、十张原图和对照图保留在本地审查产物目录（未随仓库发布）。隔离原生 QA 检查了组合节奏、暂停、减少动态与恢复；QA 不读取账号或真实曲库，不播放声音。测试与预览不证明 Apple Music 实时采样可用，也不代表用户已认可最终视觉。
